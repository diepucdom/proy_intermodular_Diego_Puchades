## Requisitos funcionales

1. **Registro de usuarios**
   - El sistema debe permitir a los usuarios crear una cuenta.
   - El sistema debe solicitar los datos necesarios para registrarse.
   - El sistema debe comprobar que los datos introducidos sean válidos.

2. **Inicio de sesión**
   - El sistema debe permitir a los usuarios registrados iniciar sesión.
   - El sistema debe permitir cerrar sesión.
   - El sistema debe gestionar los errores de autenticación.

3. **Gestión del perfil**
   - El usuario debe poder consultar sus datos personales.
   - El usuario debe poder modificar sus propios datos.
   - El usuario debe poder eliminar su propia cuenta.

4. **Interacción entre usuarios**
   - Los usuarios registrados deben poder interactuar entre ellos.
   - El sistema debe permitir bloquear a otros usuarios.
   - Un usuario bloqueado no podrá interactuar con el usuario que lo ha bloqueado.

5. **Gestión de pagos**
   - El usuario debe poder realizar pagos mediante el sistema.
   - El usuario debe poder consultar sus propios pagos y su historial.
   - Los usuarios no podrán consultar los pagos de otros usuarios.
   - El administrador podrá consultar los pagos necesarios para gestionar la aplicación.

6. **Gestión de usuarios por parte del administrador**
   - El administrador debe poder consultar los usuarios registrados.
   - El administrador debe poder bloquear y desbloquear cuentas.
   - El administrador debe poder eliminar cuentas.
   - El administrador debe poder gestionar los permisos de los usuarios.

7. **Gestión del contenido**
   - El administrador debe poder crear, modificar y eliminar contenido de la aplicación.
   - Los usuarios podrán consultar el contenido disponible según sus permisos.

8. **Seguridad**
   - El sistema debe proteger las contraseñas de los usuarios.
   - El sistema debe impedir que un usuario acceda a funciones que no tiene autorizadas.
   - El sistema debe controlar las sesiones de los usuarios.
