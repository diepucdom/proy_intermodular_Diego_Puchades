| Área | Tecnología | Uso |
|---|---|---|
| Frontend | HTML5 | Estructura de las páginas |
| Frontend | CSS3 | Diseño, responsive y animaciones |
| Frontend | JavaScript | Interactividad y comunicación con el servidor |
| Backend | PHP 8.x | Lógica de la aplicación y API |
| Base de datos | MySQL / MariaDB | Usuarios, pedidos, amigos, cupones, raids, etc. |
| Servidor | Apache | Servir la aplicación web |
| Mapas y ubicación | Google Maps API | Mapas, ubicación y seguimiento |
| Pagos | Stripe API | Pagos y gestión de tarjetas |
| Control de versiones | Git + GitHub | Control de versiones y mantenimiento |
| Dependencias | Composer | Gestión de librerías PHP |
| Diseño responsive | Bootstrap | Adaptación a móvil, tablet y PC |
| Seguridad | HTTPS + sesiones PHP + `password_hash()` | Protección de comunicaciones, sesiones y contraseñas |
| Copias de seguridad | Backups de MySQL | Recuperación ante pérdidas de datos |
| Desarrollo | Visual Studio Code | Edición y mantenimiento del código |
