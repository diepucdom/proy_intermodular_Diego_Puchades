## Delimitación del alcance

El proyecto consiste en desarrollar una aplicación web de **comida para llevar** que permita a los usuarios registrarse, gestionar su cuenta, añadir amigos, consultar ofertas, realizar pedidos y efectuar pagos mediante una plataforma externa.

La aplicación incluirá un sistema de **cupones, recompensas, misiones y raids** a restaurantes. Las raids tendrán información sobre el restaurante, ubicación mediante mapas, un periodo de tiempo limitado mediante un countdown y una recompensa en forma de cupones. También se incluirá la visualización de los pedidos, su precio, hora estimada de llegada y ubicación mediante mapas.

Los usuarios podrán gestionar sus datos personales, consultar sus propios pagos y cupones e interactuar con otros usuarios. Los administradores tendrán permisos adicionales para gestionar usuarios, contenido y cuentas.

El proyecto utilizará servicios externos para determinadas funciones, como **Stripe para los pagos** y una API de mapas para la ubicación. Estos servicios se integrarán en la aplicación, pero su funcionamiento interno y mantenimiento dependerán de sus respectivos proveedores.

Quedan fuera del alcance inicial el desarrollo de una aplicación móvil nativa, la creación de un sistema de pagos propio, la gestión directa de restaurantes y repartidores, y el desarrollo de las infraestructuras de los servicios externos utilizados. Estas funciones podrían incorporarse posteriormente mediante ampliaciones del proyecto.
