# OBJETIVOS GENERALES Y ESPECÍFICOS

## OBJETIVOS GENERALES

- Mantener funcionalidad a largo plazo: Proyecto reescalable/expandible sin cambios estructurales, solo ampliaciones ya sean físicas o digitales.

- Crear código flexible: Código actualizable sin necesidad de hacer cambios en partes que comprometan otras.

- Código separado con máximo grado de independencia: Conseguir la mayor autosuficiencia posible para fortalecer la integridad del proyecto.

- Servicios externos fiables, infalibles y transparentes de cara al cliente + información sensible opacada entre confidenciales.

- Actualización con novedades diarias/semanales, ofertas, raids...

- Renovación de código a los nuevos estándares a largo plazo.

## OBJETIVOS ESPECÍFICOS

- Seguridad de contraseñas, pago fiable, rápido y eficaz.

- Base de datos fuerte, bien relacionada y a prueba de pérdidas/borrados + copia de seguridad.

- Separación de credenciales de admin y del proyecto con contraseñas y datos cifrados y cambiantes.

- Pedir inicio de sesión al usuario cada cierto tiempo (ej. mensualmente).

- Preguntas de seguridad para recuperar contraseña/cuenta.

- Estructura web atractiva y optimizada para buscadores (Subir puestos en orden de aparición de cerca).

- Permisos y acuerdo claramente especificados + acceso a cláusula.
